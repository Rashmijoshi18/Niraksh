# Code of Conduct

We want Niraksh-Guardian to be a welcoming, constructive, and safe project for everyone.

## Expected behavior

- Be respectful, patient, and specific when giving feedback.
- Assume good intent while addressing problems directly.
- Focus criticism on ideas, code, documentation, and behavior—not people.
- Protect privacy: use synthetic examples and never share personal health information.
- Help make discussions accessible to contributors with different backgrounds and experience levels.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, sexualized conduct, doxxing, deliberate exposure of private information, and abusive or disruptive behavior are not acceptable.

## Enforcement

Project maintainers may edit, hide, or remove contributions and may restrict participation when this code is violated. Report concerns privately through GitHub rather than escalating them in a public thread.
